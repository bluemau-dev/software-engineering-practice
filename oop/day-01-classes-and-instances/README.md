# Day 1: Classes and Instances

## Exercise

Create a Python file named `cats.py`.

1. Define a `Cat` class.
2. Give each cat a name, age, and favorite activity.
3. Create an instance representing Yod.
4. Add an instance method that introduces the cat.
5. Create at least one additional cat instance.
6. Call the method on both objects.

## Reflection

After completing the exercise, explain:

- What is the class?
- What are the instances?
- Which values are instance attributes?
- Which behavior is an instance method?
